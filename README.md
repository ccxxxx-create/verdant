# Verdant（内部代号·游戏名待定）

自研 2D 塔防游戏——指挥各个世界原生的生灵，守住身后正在熄灭的家园。

经典车道式塔防玩法（资源经济 + 格子布防 + 波次进攻），首发四个世界：晨雾草原 / 珊瑚深海 / 天空浮岛 / 冰原霜境。桌面与安卓平板双端浏览器即玩，本地存档，无账号无内购。
