## 1. 游戏总览

| 项 | 内容 |
|---|---|
| 类型 | 2D 车道式塔防（Lane-based Tower Defense） |
| 玩法基准 | 资源经济 + 格子布防 + 波次进攻（该玩法结构属公共领域；命名/角色/美术/文案全部原创，见 §3.4 避嫌声明） |
| 平台 | 桌面浏览器（Chrome/Edge/Firefox/Safari 近两年版本）+ 安卓平板浏览器；横屏 |
| 输入 | PC 键鼠 + 平板触控，同一套 UI 自适应 |
| 技术栈 | Phaser 3.90 + TypeScript + Vite；GitHub Pages 部署（详见 DEV-PLAN） |
| 图形 | 程序化 SVG 矢量精灵 + 部件组合动画 + 粒子特效（现代扁平矢量 + 光效） |
| 存档 | localStorage 本地存档，无账号无后端 |
| 单局时长 | 普通关 2-4 分钟；大旗波关 5-7 分钟；生存关不限时 |
| 主线时长 | 首发四世界全通约 6-10 小时（轻度）；挑战关与生存关另计 |
| 难度定位 | 中度策略：主线轻松可过，挑战关（三星条件/限定阵容）供硬核玩家 |
| 目标帧率 | PC 与平板双端 ≥60fps（详见 DEV-PLAN 性能预算） |

**一句话定位**：在一条被薄雾笼罩的大陆上，指挥各个世界原生的生灵，守住身后正在熄灭的家园。

**首发内容范围（冻结）**：4 个世界 × 每世界 26 关 + 3 关过渡 = **107 关**；守护生物 **51 种**（攻击 25 / 生产 8 / 防御 5 / 功能 13）；敌人 **44 种**（含 Boss 4）；生存/挑战关每世界 3 个。新想法一律进 `docs/BACKLOG.md`，不进首发版。

## 2. 核心玩法循环

### 2.1 一局的结构

```
布防期（无敌人，资源积累）
   │
   ▼
波次循环：小波（10-20s）→ … → 大旗波（第10/20/30…波，敌人量×2.5，屏幕顶部旗帜动画）
   │       每个小波之间 5-12s 间隙，玩家补种/调整
   ▼
最后一波结束 → 结算（剩余时间加成+无损奖励）
```

- 胜负：消灭全部来袭敌人 = 胜；任一敌人突破最左端守护线 = 负。
- 保底机制：每行起点有一个"栅栏"（一次性阻挡，被啃食后本行失守，替代类 PvZ 的"小推车"定位，美术为各世界原生物：草原=荆棘丛、深海=砗磲门、浮岛=藤帘、冰原=冰棱闸）。

### 2.2 资源经济

- 唯一资源：**光露**。自然界四种来源在各世界有不同视觉表现（日照/暖流/风信/地热），UI 图标与数值完全一致，降低跨世界学习成本。
- 初始携带：50 光露（草原第一章教学关 75）。
- 基础生产单位每 7 秒产出 25 光露；进阶生产单位 7 秒 25 → 分阶段升至 50。
- 来源：①基础生产单位的持续产出；②天上随机掉落（每关 4-9 次，15-35 不等）；③大旗波奖励 50；④关卡首次通关奖励。
- 消耗：种下单位花费光露 + 进入各自冷却（同名单冷却 5-30 秒）。

### 2.3 格子与车道

- 地形标准：**6 行 × 9 列**（宽屏平板优先；PC 端视野完整显示）。
- 布局（从左到右）：第 1 列为守护线/栅栏位；第 2-9 列为可种植区；敌人从右侧边缘进入。
- 深海世界例外：每行为「陆 2 格 - 水 3 格 - 陆 2 格」结构（见 §4.2）。
- 浮岛世界例外：每行有 1-2 个断格缺口（飞行单位/敌人可越过，见 §4.3）。
- 冰原世界例外：右侧 3 列为冰面格（滑行特性，见 §4.4 与 §7.3）。

### 2.4 单位四职能

| 职能 | 说明 | 类比（仅为职能说明，非抄袭） |
|---|---|---|
| 生产 | 产出光露 | 经济位 |
| 攻击 | 输出伤害（单体/群体/持续） | 火力位 |
| 防御 | 高血量阻挡，无或极弱攻击 | 肉盾位 |
| 功能 | 控制/增益/地形交互 | 辅助位 |

每个世界首发 6-8 个攻击生物 + 2 个生产生物 + 1-2 个防御生物 + 3-4 个功能生物（详表见 §5）。

### 2.5 局外循环（Meta）

```
冒险地图「巡野图」选关 → 出战阵容编成（8 格卡组）→ 关卡胜利（首次+重复奖励）
   → 解锁新单位/新世界 → 挑战关与生存关 → 全收集
```

- 卡组制：出战前自选 8 个单位带入关卡（教学关默认卡组）。解锁进度存 localStorage。
- 关星：每关最多 3 星（通关/无栅栏破损/限定条件如"不用生产单位"），星星仅用于展示与挑战自我，不作硬门槛。

## 3. 世界观与命名框架

### 3.1 朴素总纲

不做宏大叙事。设定只有三句话：

1. 薄雾大陆的各个世界里，住着一群寻常的生灵（草、菌、虫、鱼、藤、苔……）。
2. 每隔一段时间，空气里会撕开"裂隙"，钻出啃食一切的怪兽。
3. 玩家是路过此地的"看火人"——一个看清了裂隙规律、指挥生灵守住防线的人。玩家不出场、不扮演角色，只作为指间的一束光。

各世界之间只有"裂隙越来越密"这一个递进关系，没有统一反派、没有世界观谜语。

### 3.2 命名总规则

- 攻击生物：**世界原生物种名**，两到三字，口语可念，不带"灵/神/圣/魔"等大字。
- 敌人：**兽群物种名**，两到三字，突出啃食/坚硬/成群的特征。
- 建筑/地形物：功能直白命名。
- 前缀用于代码统计与掉落物归类，不进入 UI 文案。

### 3.3 各世界命名风格表

| 世界 | 生物命名风格 | 敌人命名风格 | 命名示例 |
|---|---|---|---|
| 晨雾草原 | 草本植物/菌类/小虫日常名 | 行蚁类/啮齿类/披甲兽 | 萤茅、盘苔、鼓菇、刺豆 |
| 珊瑚深海 | 海洋生物/珊瑚/浮游名 | 沉骸/甲壳/触手类 | 灯芯珊瑚、沙泡虾、铃贝 |
| 天空浮岛 | 藤蔓/羽虫/风籽名 | 风蚀/猛禽类 | 缠云藤、羽蝉、风哨草 |
| 冰原霜境 | 苔藓/雪绒/耐寒生物名 | 霜鬣/冻穴类 | 星苔、雪绒兔、暖石菇 |

### 3.4 避嫌声明

- 玩法结构（车道格子、阳光式经济、波次、大旗波）为塔防品类的公共设计范式，本作仅沿用范式。
- 本作不出现、不引用、不戏仿受版权保护的具体角色名、外形、台词、音乐；全部单位与敌人为原创命名与原创矢量造型。
- 关卡场景描述、文案、音效均为原创。

## 4. 世界设定

> 冒险地图总名：**巡野图**。四个世界在图上自南向北（或自西向东）依次排列，通关前一世界主轴后才解锁下一世界。

### 4.0 巡野图结构

- 一张可横向滚动的长卷地图，四个区域由雾霭/海峡/云层/暴风雪带分隔；分隔带本身是"过场小关"（每个 1 关，用作机制引入，原作则取消——保留简单点：世界间各 1 关过渡关，共 3 关）。
- 每世界区域含一个**区域小地名**（PvZ 式关卡节点容器）：

| 世界 | 区域小地名链 | 关卡节点数 |
|---|---|---|
| 晨雾草原 | 雾岬 → 草海 → 萤原 | 10 + 8 + 8（含 Boss 关，共 26） |
| 珊瑚深海 | 暖滩 → 灯礁 → 静海沟 | 8 + 8 + 10（含 Boss 关，共 26） |
| 天空浮岛 | 云脊 → 风眼 → 浮墟 | 8 + 8 + 10（含 Boss 关，共 26） |
| 冰原霜境 | 冻湖 → 霜径 → 白喉 | 8 + 8 + 10（含 Boss 关，共 26） |

- 每世界末 3 关固定为：大旗波加强关 → 生存关 → Boss 关。
- 每世界各有 2 个挑战关（三星条件关，藏在小地名链第 2 段）。

### 4.1 世界一：晨雾草原（Meadow）

- **主题**：一切开始的地方。低饱和的草绿、雾白、淡金；晨雾贴地滚动。
- **地形机制**：标准 6×9 陆地格。无特殊地形，作为教学场。
- **新增地形物**：高处草丛（第 3-4 行，遮挡远程低射程单位视线——仅影响草原专有单位"投掷系"的命中判定，其他世界不出现）。
- **光照**：白昼，光露图标为金黄色露珠。
- **Boss**：石皮巨兽（高甲低速，召唤小兽群；弱点=持续伤害类单位）。
- **教学序列**（前 5 关）：种下第一株 → 生产光露 → 认识波次 → 第一次大旗波 → 栅栏失守与失败。
- **登场单位摘要**（详表 §5.3，共 13）：萤茅/双穗灯（生产）、刺豆、三叉箭草、冰纹豆、火绒草、鼓菇、投雾菇、雷伞菌（攻击 7）、木芯壳（防御）、牵引苔、蜜腺草、雾灯草（功能）。
- **登场敌人摘要**（详表 §6.2，共 10+1）：行蚁、铁喙雀、啮背鼠、灰潮群、藤蟒、织网蛛、举壳兵、啃藤兽、吮光蛾、石皮兽 + Boss 石皮巨兽。
- **关卡节奏**：前 5 关单波 1-2 只教学 → 第 2 段双怪混波 → 第 3 段起大旗波 2.5 倍量；Boss 关只出 Boss + 稀疏护卫。

### 4.2 世界二：珊瑚深海（Reef）

- **主题**：沉在暖流里的城市废墟，灯芯珊瑚是仅剩的光。青蓝、紫、荧光橙。
- **地形机制**：每行「陆 2 格（左）- 水 3 格（中）- 陆 2 格（右）」；水格只能种水生单位，陆格只能种陆生单位；敌人分陆行/水行两套行径路线。
- **新增机制**：暖流井（地图中 2 口固定井位，向两侧水格周期性推动光露——视觉上光露顺流过格，玩家点击收取；收取型掉落物与持续产出的混合）。
- **导电连锁**：水格带电（见 §7.2），水生电系单位可跨水格传导。
- **登场单位摘要**（详表 §5.4，共 13）：灯芯珊瑚/铃贝双珠（生产，限水格）、沙泡虾、棘冠藻、电鳗须、灯笼鱼、藤壶枪、砾背螺（攻击 6）、砗磲砲（防御）、墨汁管、牵引海葵、磷光苔、吞光贝（功能 4）。
- **登场敌人摘要**（详表 §6.3，共 10+1）：沉藻兵、涌鱼群、钳潮蟹、触须鳗、溺行骸、硬礁龟、沉船哨、吸光蛸、腐骨鳐、母巢触 + Boss 沉骸母兽。
- **关卡节奏**：第 1-2 关陆行怪→第 3 关起水行怪与陆行混波→第 2 段母巢触召唤压力→第 3 段硬礁龟（铁甲）检验钝击配置；Boss 关沿水路推进。
- **Boss**：沉骸母兽（沿水路由右向左，间歇张开吸口吸附最近水生单位 2 秒；弱点=硬控）。

### 4.3 世界三：天空浮岛（Sky Isles）

- **主题**：云上的破碎群岛，风是这里的规则。蓝、白、藤绿、暖橙云。
- **地形机制**：每行 1-2 个**断格**（无地板）；陆行敌人遇断格停下 1.5 秒后绕行或止步；飞行敌人直接越过；只有"蔓生系"单位可种在断格上（延伸根系到邻格）。
- **新增机制**：风向带（每关固定风向，左风加速向左移动的单位与敌人、减速向右；右风相反；每 60 秒换向一次，UI 顶部风向标提示）。
- **登场单位摘要**（详表 §5.5，共 13）：风籽草/云绒双穗（生产）、羽蝉、缠云藤、风哨草、鸣雷雀、飘絮菌、啄壳雀（攻击 6）、硬壳豆、芦根壳（防御 2）、浮泡菇、牵根蔓、光合苔（功能 3）。
- **登场敌人摘要**（详表 §6.4，共 10+1）：蚀岩蜂、撞壳牛、藤缠兽、云鳐、断翼鸦、噪鸣蝉、衔壳兵、糙皮猿、蚀巢鹰、风哨贼 + Boss 风鸢首领。
- **关卡节奏**：第 1-2 关地面怪→飞行波登场→第 2 段撞壳牛冲撞检验肉盾→第 3 段飞行混编；断格行的绕行为固定压力点。
- **Boss**：风鸢首领（飞行，周期性俯冲抓走一行最左单位；弱点=对空火力）。

### 4.4 世界四：冰原霜境（Frost）

- **主题**：冰封的旧河湾，光是暖的，冰是滑的。白、冰蓝、松绿、暖黄光源。
- **地形机制**：标准 6×9；右侧 3 列为冰面格：陆行敌人在冰面移动速度 ×1.35；其上不可被"缠绕系"单位定身；火系单位攻击冰面会暂时融出 1 格水格（存在 20 秒，水格带电）。
- **新增机制**：地热（天上掉落光露替换为地热喷发：地图中 2 处地热裂缝每 14 秒喷发一次 25 光露，可被怪物站立 3 秒或偷暖贼踩踏中断；初始携带与大旗波、首通奖励不变，仍为 §2.2 口径）。
- **寒潮事件**：每关第 15 波起，每 45 秒全场寒潮 5 秒：所有单位攻击速度 -25%（火系 -10%），冰面格面积临时扩大 1 列（左侧）。
- **登场单位摘要**（详表 §5.6，共 12）：星苔/暖石菇（生产）、冻豆、霜刺草，火岩荠，冰棱薯，地脉菇，碎冰锤草（攻击 6）、硬冰坨（防御）、融雪菇，暖流苔，牵霜蔓（功能）。
- **登场敌人摘要**（详表 §6.5，共 10+1）：霜鬣狼，雪绒兔群，冰穴蛛，冻壳蟹，寒潮鸦，冰芯巨人，碎冰蟒，偷暖贼，冰镜眼，白喉幼兽 + Boss 霜鬣狼王。
- **关卡节奏**：第 1-2 关霜鬣狼群速压→第 2 段冰芯巨人（铁甲）与冰镜眼（反射）登场→第 3 段寒潮+冲锋混编；冰面扩张期是难点峰值。
- **Boss**：霜鬣狼王（高速，沿冰面冲锋无视定身，撞碎第一个遇到的单位；弱点=减速/软控与爆发）。

## 5. 单位体系（守护方生物）

### 5.1 通用规则

- 所有单位上火线为 **HP 300**（肉盾类除外）；被啃食致死即消失，格子释放。
- 造价/冷却/伤害等全部可在 `data/archetypes/*.ts` 中配平（M0 建立该目录）；本表为冻结基准值。
- 升级替代：同名高阶单位直接替换卡组（非叠种），例：萤茅→双穗灯。
- 攻击单位三类射程：近战（1 格）、直射（本行无限）、散射/抛射（越过障碍或跨行）。
- 对空规则：标注「对空」的单位可攻击飞行敌人；未标注者对飞行敌人伤害无效。

### 5.2 数值锚点（全表基准，调平时只动系数不动结构）

| 锚点 | 数值 |
|---|---|
| 初始光露 | 50（教学关 75） |
| 基础生产 | 25 光露 / 7 秒 |
| 单体普攻基准 | 造价 100｜20 伤害 / 1.4s｜HP 300｜冷却 5s |
| 肉盾基准 | 造价 50｜HP 4000｜冷却 25s |
| 重型系数 | 比基准更硬的肉盾按"造价×2、HP×1-2"浮动（砗磲砲 = 基准×1.x；芦根壳 = 基准×2 造价 / ×2 HP），须在表内注明 |
| 减速基准 | 40% / 2 秒 |
| 草原小怪血线 | 50 – 600 |
| 护甲减伤 | 布 0% / 皮 20% / 壳 40% / 铁 65%（见 §6.1） |

### 5.3 晨雾草原首发单位（13）

| 单位 | 职能 | 造价 | 冷却 | HP | 攻击 | 射程/方式 | 特性 |
|---|---|---|---|---|---|---|---|
| 萤茅 | 生产 | 50 | 5s | 300 | — | — | 每 7s 产 25 光露 |
| 双穗灯 | 生产 | 125 | 15s | 300 | — | — | 每 7s 产 50 光露 |
| 刺豆 | 攻击 | 100 | 5s | 300 | 20/1.4s | 直射 | 基准单体 |

## 7. 地形与连锁反应

> 首发批次**仅启用本章机制**（用户拍板：机制要朴素）。所有其他候选机制（单位融合、敌人进化、昼夜、拖拽法术、跨世界混合关等）进 `docs/BACKLOG.md`。

### 7.1 格状态机（地基）

每个格子同一时刻只保留一种环境状态，状态转换规则固定，供全系统查询：

```
enum CellState { Normal, Water, Burning, Electrified }
状态裁决：新状态覆盖旧状态；唯一例外是电气化只能从 Water 进入（水被蒸干=Normal，不可被通电）
冰面格(FrostGround)与陆格(Ground)是两种地板类型，独立于 CellState；冰面被火烧=融化出 Water 状态
```

### 7.2 导电（限深海与冰原融水格）

- 触发：电属性攻击命中处于 `Water` 状态的格子，该格进入 `Electrified`，持续 8 秒。
- 连锁：`Electrified` 格向上下左右相邻 `Water` 格传导（广度优先，最多 3 跳，每跳延迟 0.3 秒）。
- 效果：`Electrified` 格上的敌人每 0.5 秒受到 20 点真实伤害（无视护甲）；格上水生友军暂停攻击 0.5 秒（敌我不分，谨慎使用）。
- **铁甲敌人（硬礁龟）受到的传导伤害减半；Boss 不参与此修正。**
- 沉底规则（§6.3）：敌人被减速累计 ≥3 秒进入"沉底"（移速再 ×0.5，免疫电击），解除减速 2 秒后恢复。

```pseudo
onElectricHit(cell):
  if cell.state != Water: return
  visited = {cell}
  bfs = [{cell, hops:0}]
  while bfs:
    cur = bfs.shift()
    cur.cell.state = Electrified; cur.cell.timer = 8.0
    if cur.hops < 3:
      for n in neighbors(cur.cell):
        if n.state == Water and n not in visited:
          visited.add(n); bfs.push({n, cur.hops+1})
```

> 实现备注（M0 细化）："每跳延迟 0.3 秒"用定时队列表达入队延迟，非同步展开；对已 Electrified 格重复触达仅刷新计时器（幂等）。

### 7.3 火与冰（冰原主打，草原火系为引子）

- 火属性攻击命中：目标敌人挂灼烧 5 秒（每秒 15 点，可刷新不叠层）；命中的格子分三种情况：
  - 陆格（普通地形）→ 草地类地形（草原）进入 `Burning` 5 秒并向相邻草格蔓延 1 次；深海/浮岛陆格不蔓延。
  - 水格 → 变 `Normal`（蒸汽）20 秒，期间不可种植。
  - 冰面格 → 融化为 `Water` 20 秒（水格规则随之生效，可导电）。
- 蔓延概率：草原草格基础蔓延概率 60%；寒潮期间 ×0.5。
- 寒潮（§4.4）期间的修正只算**伤害**、不算攻速：火属性伤害 -25%（寒潮对火系攻速的 -10% 修正另计，见 §4.4）；寒潮减伤与火抗（×0.7）为乘算关系。
- 火系对标注"火抗"敌人（石皮兽、沉骸母兽）伤害 ×0.7。

### 8.2 波次导演公式（可计算，非散文）

```
每波点数预算:
  budget(w) = round( BASE × (1 + w × GROWTH) × WORLD_M × FLAG_M )
  w 从 1 起计; BASE = 8, GROWTH = 0.35
  WORLD_M: 草原 1.0 / 深海 1.15 / 浮岛 1.3 / 冰原 1.45（存活关另计 ramp）
  FLAG_M: 大旗波 2.5, 其余 1.0
  第 1 波固定只有基础小怪：预算锁定为 BASE（8 点），不参与公式上浮

敌人点数消耗:
  points(enemy) = round(HP / 50) + traitBonus
  traitBonus: 飞行+2, 水行+1, 免疫减速+2, 冲撞/抓取+3, 召唤+4, Boss 不计入预算池

选怪规则:
  1. 仅从本关"已亮相池"中加权随机（每个敌人须先在早 3 波内亮相过至少 1 只）
  2. 连续 3 波不得选同一敌人；同波最多 2 种敌人
  3. 剩余预算 < 1.2×max(points) 时提前收波（避免全精英波破坏节奏）

出生间隔:
  同波内: clamp(1.4 - 0.02×w, 0.6, 1.4) 秒/只；成群敌人间隔 0.4s
  波间: clamp(12 - 0.25×w, 6, 12) 秒；大旗波后 5 秒

生存关难度 ramp:
  每存活 30s, WORLD_M += 0.15（ WORLD_M 上限 3.0，防数值爆表）
  每存活 5 分钟, 新敌人从"本世界未亮相敌人池"进已亮相池
```

### 8.3 每世界关卡表（结构）

| 段 | 关卡 | 类型 | 解锁/亮相内容 |
|---|---|---|---|
| 第 1 段 | 10 关 | T-TEACH×5 + T-NORMAL×5 | 生产/攻击/功能三类初见了；亮相敌人 1-6 |
| 第 2 段 | 8 关 | T-NORMAL×6 + T-CHAL×2 | 亮相敌人 7-8；解锁第 2-3 个新单位 |
| 第 3 段 | 8 关 | T-NORMAL×5 + T-FLAG + T-SURVIVE + T-BOSS | 亮相 9-10；解锁 4 号位新单位；末 3 关固定为大旗波加强关 → 生存关 → Boss 关（与 §4.0 一致） |
| 过场 | 3 关 | 每世界间 1 关过渡（=下一世界 T-NORMAL 简化：新地形机制亮相关） | 引入下一世界地形 |

总关数：4×26 + 3 = **107 关**（首发冻结值）。

### 8.4 三星条件池（挑战关）

任选其一写入关卡 `starCondition`：
① 不使用任何生产单位通关；② 出战卡组 ≤6；③ 通关时场上单位 ≤12；④ 不用火系单位；⑤ 不用电系单位；⑥ 90 秒内通关；⑦ 无栅栏破损且不铲除任何单位。

### 8.5 单位解锁表（规则）

- 世界内新单位 = 通关对应关卡的首次奖励，解锁后进入可编成池。
- 前一世界至少 8 个单位已解锁，才开放下一世界编成携带跨世界单位（跨世界单位仅限生产+防御类，控制复杂度——朴素原则）。
- 高阶替代单位（双穗灯等）在对应世界第 2 段解锁后自动替换卡组槽位。

## 11. 美术规范（程序化 SVG）

### 11.1 角色部件规范

- 每角色拆 **≤6 个部件**（body/head/weapon/eye 等），统一 viewBox `0 0 100 100`，锚点中心 (50,50)。
- 描边宽 2-3px（星苔等小体型 2px），圆角端点；**禁用滤镜/渐变网格**（保证跨引擎渲染一致与烘焙性能）。
- 运行时按设计 2× 光栅化（200×200），平板高分屏不糊。
- 角色配色 ≤4 色 + 1 描边色；色板取自 §10.2 世界色板，禁止世界间借色（浮岛/深海例外：云蓝与水青可作彼此的辅色 10%）。
- 文件/纹理键命名：`{world}_unit_{id}_{part}` / `{world}_enemy_{id}_{part}`，例 `meadow_unit_firefly_reed_body`。

### 11.2 背景与地形

- 每世界背景 3 层视差（远/中/近），SVG 横向平铺；雾=半透明大多边形 + 12s 慢速横向 tween（高档 + 粒子雾）。
- 地形格：草地 6 色阶微差（按行错峰）、水格两层波纹循环（正弦位移）、冰面高光斜切、断格=边缘碎角。
- 光露图标：晨金露珠 4 帧呼吸缩放（数据化 clip）。

### 11.3 特效规范（全部引擎内程序化）

| 事件 | 表现 | 预算 |
|---|---|---|
| 命中 | 3-5 粒子 + 受击部件闪白 80ms | ≤5 粒子/次 |
| 击杀 | 部件爆散 + 200ms 淡出 | ≤12 粒子/次 |
| 种植 | 土圈扩散 + 部件 scaleY 0.2→1（300ms 弹性） | ≤8 粒子/次 |
| 大旗波 | 旗帜升起 + 屏幕微震（100ms ≤8px）+ 铜管音 | 屏幕全局 1 次 |
| 火 | 橙红粒子柱 + 地面焦痕贴花 5s | ≤10 粒子/次 |
| 电 | 锯齿折线 tween 描边 + 蓝白闪烁 | 每跳 1 条 |
| 冰 | 冰晶炸裂 + 冰冻贴花 | ≤8 粒子/次 |

## 12. 音频规范

### 12.1 策略：程序化合成为主

- 全部音效用 **WebAudio 振荡器+噪声实时合成**（约 30 个音效，总计代码 <500 行）：零外部资源、零授权风险、包体增量 ≈0、可随时调参。
- 音效表：种植=木鱼 820Hz 80ms 衰减；射击=短噪点 30ms 带通；命中=木质点击 1.2kHz；爆炸=低频噪声 burst 200ms；大旗波=铜管三音 1.2s；种植冷却好=上行单音；失败=下行三度 0.8s；胜利=五音琶音。

### 12.2 音乐

- 每世界 1 首程序化环境 pad（三和弦 + 慢 LFO + 世界特色音色：草原=木琴点缀、深海=正弦长音、浮岛=风噪垫、冰原=玻璃质感方波），战斗时叠加低频脉冲层（紧张度由波次驱动）。

### 12.3 授权与替换

- 程序化合成天然无版权问题。若 M6 追求更高音质，替换源仅限可验证 CC0（freesound CC0 / OpenGameArt），替换时逐条验证授权并记录于 `docs/AUDIO-CREDITS.md`。
