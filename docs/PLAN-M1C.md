## 2. 目标与分级依据

**目标**：7 条问题全部闭环 + 草原 1-1~1-5 可玩 + 打击感件套补强。**复杂任务**（美术全量重制 + 战斗场景重构 + 新关卡数据 + 视觉新面）。

**视觉设计方案（第一层闸门·反默认基线）**：
- 具名色板（明亮草原，无 AI 默认脸）：晨天蓝 `#A5DFF7`/`#CFEEFB`、亮草绿 `#7CC96F`/`#93DA80`、新叶绿 `#57C173`/`#86DC92`/`#A8E58F`、光露金 `#FFD34D`、奶油 `#FFF0C2`、深绿描边 `#26402F`
- 字体角色：界面数字用粗体无衬线（system-ui），标题同族
- 布局概念（PvZ 式，公开常识）：顶部信息条（阳光计数/波次/倍速）→ 水平种子卡条 → 6×9 草坪 → 左侧篱门；**任何 UI 不与草坪重叠**
- 签名元素：白睛黑瞳+腮红的可爱植株；从天空飘落、落地停留、可点击收集的金色光露；受击闪白+碎屑+飘字；最后一波"一大波敌人来袭！"横幅+震屏

## 5. 留痕裁决表

| # | 裁决 | 理由 | 错了损失什么 |
|---|---|---|---|
| C-D1 | 敌人速度语义改为"格/秒"并压到 0.12~0.35（原 0.4~1.2 格/秒=横穿草坪仅 7~22s，是难度过高首因） | PvZ 普通僵尸横穿约 40s+（公开常识）；原值无出处 | 节奏偏慢，可回调 |
| C-D2 | 1-1 起步光露 75→150、首波 8s→20s | 原值首波时玩家买不起任何输出（75<100 豆射手），必败体验 | 前期更宽松，贴合教学关定位 |
| C-D3 | 篱门=割草机式一次性护盾（每行一块，触发后销毁并击杀来敌） | 用户要求参考 PvZ；同时直接降低挫败感 | 与原"触线即败"设定偏离，GDD §8.4 同步 |
| C-D4 | 种子条改 PvZ 式水平顶条（原左竖排压住草坪左缘观感） | 直接消除"槽位与草地覆盖"结构性问题；移动端拇指可达 | 顶部占用 148px，草坪高度 768→减小行高 128，仍 > PvZ 比例 |
| C-D5 | 单位精灵用生成器（脚本产出字符矩阵）而非逐格手写 | 13 张×32 行手写出错率高；生成器可复用于后续世界；仍是纯代码像素 | 引入 scripts 依赖（已在 normalize-pixels.mjs 先例内） |
| C-D6 | 亮度底线写入测试（关键色相对亮度≥阈值） | 防回归到"太暗"；用户两次明确否决暗色 | 极小 |
| C-D7 | 不做世界能量/传送带实装（M1C 只做手感+前 5 关） | 本轮 7 条问题全部指向战斗手感/美术，机制扩展属 M2 | 丰富度延后 |
| C-D8 | unlockUnits 语义=本关固定卡组（通关后重打 1-1 仍 2 卡），非"已解锁全集" | 关卡难度随卡组成长设计（代码审查 P2-9 留痕）；后期重玩旧关=低配挑战 | 若用户预期"全集卡组"需改 1 行并同步测试 |
