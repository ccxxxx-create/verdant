# 单位立绘同质化治理 · PvZ 式“同模板强辨识”

## 目标与判定标准

用户标准（原话参照）：**像 PvZ1 的豌豆射手 vs 寒冰射手——同一株植物的骨架，但一眼能分出彼此**。本轮不是推翻模板（那是历史上被否决两次的方向），而是把差异化从“头顶一小撮装饰”放大到“整体气质一眼可分”。

治理对象（勘察量化结论）：14 单位中 6 个共享同一个绿身体模板（行 11-29 逐字节相同），`frost_pea` 与 `ember_fluff` 像素相同率 90.9%；另有 3 对克隆（萤火/双灯、雾菇/闪电菇、蜜草/雾灯）；`thorn_pea` 独有像素仅 5.6%。

## 红线（不可违反，来自 GDD §11 + 既有纪律）

1. 纯代码字符矩阵，32×32，零图片文件；
2. palette 26 色登记制，新增色必须登记，亮度底线测试守护；
3. 脸五件套保留：白睛黑瞳+瞳内高光+三阶明暗（K/M/L 结构不变，改为可参数化选色）；
4. 职能特征件置顶 + 内容垂直居中（格心锚点不变，保 14 处显示面零偏移）；
5. 唯一所有者：只改 `scripts/gen-pixel-units.mjs` 后重跑，不手改 `meadow.ts`；
6. 允许职能破例（本轮用户批准）：地雷/灯柱类可去腮红/微笑嘴；
7. 不新增单位 → pixels/registry/economy 计数门不动。

> 口子说明（依据 GDD:703“同骨架换色系+特征件”）：元素单位的元素色从“头顶件”扩展为“身体主色”（冰豆身体掺冰蓝、火豆身体掺火红、电菇紫身）——这是 PvZ 正统做法（寒冰射手蓝身），属特征件色彩的延伸，不是世界色板变更；世界基底仍是草原草绿系。

## 方案比选

| 方案 | 背景 | 内容 | 预期收益 | 成本/风险 | 结论 |
|---|---|---|---|---|---|
| A 全量重制 | 14 个全同质 | 全部手绘新函数 | 辨识度天花板 | 工作量大、脸谱统一性易破 | 弃选：用户选优先拆克隆对 |
| B **拆克隆对+参数轴** | 9 个单位贡献了几乎全部雷同 | 参数化体态/色系/表情，重绘 9 个 | PvZ 级一眼可分 | 中；参数轴统一可控 | **采用** |
| C 只改特征件 | 保持身体模板 | 重绘头顶件 | 快 | 天花板低，frost/ember 仍近 clone | 弃选：用户明确模板可同但要一眼分 |

## 实施内容

### 1. 生成器参数轴（`scripts/gen-pixel-units.mjs`）
- `body(g, cx, cy, rx, ry, main, hi, lo)`：色系参数化（现恒 M/L/D；新增 I/i、R/r、P/Z、B/N 组合），形态参数沿用 rx/ry 但实际使用 ≥3 种体型；
- `eyes(g, cy, gap, pupilDx, mood)`：表情变体 cool（半眯冷脸）/calm/aim（瞄准专注）；
- `smile(g, y, kind)`：嘴型变体 grin/closed(o 型/严肃抿嘴)；
- 腮红按职能可选关（破例单位）。

### 2. 九个单位重绘要点（同骨架，气质分流）

| 单位 | 现状问题 | 新设计（一眼可分点） |
|---|---|---|
| frost_pea 冰豆 | 与火豆 90.9% 同像素 | **冰蓝身体**（I/i）+ 严肃 cool 脸，头顶冰晶保留为“霜冠” |
| ember_fluff 火豆 | 同上 | **火橙红身体**（R/r）+ 咧嘴笑，头顶火苗保留 |
| firefly_reed 灯心草 | 与双灯逐字节同体 | **瘦高体型**（rx7×ry9）+ 萤火虫绕身 G 光点 + 侧叶 |
| twin_glow 双灯草 | 同上 | **矮墩体型**（rx9×ry6）+ 头顶双灯为绝对视觉焦点 |
| lob_shroom 雾菇 | 与闪电菇柄部克隆 | **扁横大伞盖**（rx10×ry4）+ 雾汽 B/I 斑点，呆脸 |
| storm_cap 闪电菇 | 同上 | **高束伞盖**（rx7×ry8）+ y 闪电标 + 怒目脸（mood=aim） |
| nectar_moss 蜜草 | 与雾灯同体 | 花冠 f 放大为“花仙”造型，笑脸上扬 |
| mist_lamp 雾灯 | 同上 | **破例去脸**：灯罩 N 顶梁 + 灯笼 G/y 灯体 + 底座，无五官（职能物件化） |
| thorn_pea 豆射手 | 独有像素 5.6% | 发射管强化（B 弹仓）+ aim 专注脸（侧目） |

其余 5 个（trifold_arrow/drum_cap/wood_core/tether_moss/dandelion）仅参数微调（体型/嘴型），不动构图。

### 3. 样张轮（用户拍板：先样张后全量，项目既定纪律）
一次性 Python PIL 脚本（不落库，`/tmp` 执行）：读新矩阵 → 放大 4× → 新旧并排拼图 → 先自我评审（可读/可爱/明亮三判据 + 一眼可分检验），再交用户看拼图确认后才重跑生成器落盘。

### 4. 落地面
1. 改 `gen-pixel-units.mjs`（新增参数轴 + 9 函数重绘）→ 重跑生成；
2. `npx tsc --noEmit` + `npx vitest run`（四闸：矩形/色板/亮度/id 对齐 全绿；计数门不变量）；
3. IAB 实机：图鉴页 + 战斗 + 商店 + 选卡 4 处显示面截图确认（各显示倍率 0.78/0.85/1.3/原生下的辨识度）；
4. 独立只读审查子代理（矩阵合法性 + 风格一致性 + 剪影互异检验：任意两单位逐行相同率须 <50%）；
5. 提交推送 + CI 部署，平板上验证。

## 验收口径
- 四测试闸全绿；
- 14 单位两两逐行相同率全部 <50%（同族元素对 frost/ember 允许 <70% 但必须“整体色相可分”）；pairwise 由审查子代理量化出数；
- 样张自评 + 用户拼图确认（P0 未过不量产）；
- IAB 图鉴/战斗截图过“一眼可分”目检。
